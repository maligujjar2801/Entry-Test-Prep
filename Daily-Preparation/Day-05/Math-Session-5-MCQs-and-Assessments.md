# Part II — Answer key and explanations

**Do not use this section until you have submitted your attempt.**

| Q | Answer | Explanation |
|---:|:---:|---|
| 1 | C | Adding outside the function changes outputs: up 4. |
| 2 | B | \(x-6\) shifts the graph right 6. |
| 3 | B | The output changes sign: \((x,y)\to(x,-y)\). |
| 4 | C | The input changes sign: \((x,y)\to(-x,y)\). |
| 5 | B | Every y-value is multiplied by 5. |
| 6 | B | \(f(4x)\) divides old x-coordinates by 4. |
| 7 | A | Every output is multiplied by \(1/2\). |
| 8 | B | For \(f(2x)\), new x is old x divided by 2: \(8/2=4\). |
| 9 | A | \(y\) becomes \(-2y\): \(-2(-3)=6\). |
| 10 | C | \(f(3x)\) maps \((x,y)\to(x/3,y)\). |
| 11 | B | Vertex form \(a(x-h)^2+k\) has vertex \((h,k)\). |
| 12 | B | \(x+3=x-(-3)\), so vertex \((-3,7)\); negative coefficient means downward. |
| 13 | B | \(x+2\) shifts left 2; outside multiplier stretches vertically; \(-4\) shifts down. |
| 14 | C | Vertex form gives \((2,-5)\). |
| 15 | B | Left 3 means \(x+3\); x-axis reflection adds a negative outside; up 1 adds \(+1\). |
| 16 | B | Square-root input must satisfy \(x-7\ge0\). |
| 17 | B | The square root is nonnegative, then 2 is added. |
| 18 | B | Maximum occurs at vertex y-value 4; the parabola opens downward. |
| 19 | C | \(2|x-4|-6\) has vertex \((4,-6)\). |
| 20 | B | Factor 2 inside compresses horizontally by \(1/2\); negative input also reflects across y-axis. |
| 21 | A | \((x,y)\to(x+4,2y-3)=(10,7)\). |
| 22 | B | Vertex \((-2,3)\); negative leading coefficient gives downward opening. |
| 23 | B | Require \(2x\in[-4,6]\), hence \(x\in[-2,3]\). |
| 24 | B | Transform both endpoints: \(-2(-2)+1=5\) and \(-2(5)+1=-9\); order them from least to greatest, giving \([-9,5]\). |
