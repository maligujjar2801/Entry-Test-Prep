## Concepts

### Slope
m = (y2 - y1) / (x2 - x1)

- Positive slope: line rises.
- Negative slope: line falls.
- Zero slope: horizontal line.
- Undefined slope: vertical line.

### Line Forms

Slope-intercept: y = mx + c

Point-slope: y - y1 = m(x - x1)

Two-point: y - y1 = [(y2-y1)/(x2-x1)](x-x1)

General: Ax + By + C = 0, with slope m = -A/B when B is nonzero.

### Parallel and Perpendicular
Parallel non-vertical lines: m1 = m2.

Perpendicular non-vertical lines: m1*m2 = -1.

Horizontal: y = k.

Vertical: x = k.

### Intercepts
x-intercept: set y = 0.
y-intercept: set x = 0.

## Entry-Test Recognition

- “parallel” → same slope
- “perpendicular” → negative reciprocal
- “horizontal” → y = constant
- “vertical” → x = constant
- “x-intercept” → y = 0
- “y-intercept” → x = 0

## Worked Examples

For (2,3) and (6,11): m = (11-3)/(6-2) = 2.

If a line has slope 4, a perpendicular line has slope -1/4.

A line through (2,5) with slope 3 is y-5=3(x-2), hence y=3x-1.
