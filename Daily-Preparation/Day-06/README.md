## Core rules to remember

- Order matters: permutation.
- Order does not matter: combination.
- Repetition allowed in independent positions: \(n^r\).
- No repetition: choices decrease.
- For even numbers, choose the units digit first.
- Zero cannot be the first digit of a multi-digit number.
- Use complement counting for “at least one” and “not together” when easier.
