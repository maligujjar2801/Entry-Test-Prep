# Entry-Test-Prep

My complete preparation journey for **NUST NET + FAST/NUCES** admission tests.

## Preparation Method

**Concepts → Entry-Test Recognition → Worked Examples → MCQ Practice → Timed Mini-Test → Error Analysis → Revision**

Each session aims to keep the first conceptual model simple, build toward deeper entry-test reasoning, and finish with a timed set of MCQs and explanations.

- \`NET/\` — NUST NET Mathematics, Physics, English

- \`Revision/\` — revision material

## Session Standard

- Explain the idea in plain language before introducing equations.
- Use readable LaTeX math and define symbols and units.
- Include worked examples and recognition strategies for MCQs.
- Test conceptual depth with 25–30 questions.
- Keep answers and explanations after the test so the attempt can be timed honestly.
- Use performance and error patterns to decide the next revision target.
